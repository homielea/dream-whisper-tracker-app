# Dream App software-factory contract

This repository is an active product in LeaOS HQ.

## Product invariant

Dream-symbol material is exploratory and reflective. Never present symbolic meaning,
mental-health conclusions, or lucid-dreaming guidance as diagnosis, certainty, or fact.

## Working agreement

- Keep each task narrow enough for one reviewable pull request.
- Work on a dedicated branch; never commit directly to `main`.
- Preserve the existing visual language and mobile-first experience.
- Run `npm ci`, `npm run lint`, and `npm run build`.
- Do not merge, deploy, publish, change billing, or alter production data.
- The pull request must state: outcome, checks, risks, and decisions needed from Lea.
- If requirements are ambiguous in a way that changes user experience or safety,
  stop at a proposal and request a decision in the pull request.

## Factory trigger

Only repository-owner issues whose title begins with `[Factory]` are dispatched.
All unattended work ends in a pull request for human review.
